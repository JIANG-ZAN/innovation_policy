# 分支变量与延迟回响

本文档用于统一各章逻辑，避免对白、状态和结局条件互相矛盾。它是叙事设计规则，不是技术实现代码。

## 初始状态

所有状态限定在0—5之间。

| 状态 | 初始值 | 含义 |
|---|---:|---|
| 自主 | 2 | 拒绝建议、承担决定和划定边界的能力 |
| 辨识 | 1 | 查看证据、理解模型局限和纠正AI的能力 |
| 联结 | 1 | 现实中能够共同承担生活的人际关系 |
| 保障 | 2 | 健康、财富、住房和制度资源 |
| 意义 | 1 | 对学习、工作和生活理由的理解 |
| 公共影响力 | 0 | 隐藏状态，个人事件进入公共制度的程度 |

## 条件分支规则

### 少年期公开申诉

- 拥有`查证习惯`：发现模型偏见，申诉成功。
- 没有`查证习惯`：申诉在个案层面失败，但公共影响力照常增加。
- `无植入`不等于无法成功；玩家可使用公开终端和现实调查资料。

### 小满关系（男性终身朋友线）

小满在默认剧本中是与林一同岁的男性朋友。该关系只记录友情、信任和现实互助，不与伴侣匹配或恋爱状态绑定。

1. 幼年选择实地调查：获得`小满羁绊`。
2. 少年选择签署报告：羁绊变为`小满决裂`，后续不再提供现实支持。
3. 少年公开申诉：保留或重新建立普通羁绊。
4. 少年秘密帮助：强化羁绊，并获得`地下互助`。
5. 壮年进入昼海：有羁绊时保留“离线夜”；无羁绊时增加`现实孤立`。
6. 中年非法治疗：羁绊或地下互助可以转化为`社区支援`。

### 中年期人类复核

满足以下任一条件即可个案胜诉：

- 辨识达到4。
- 拥有`查证习惯`。
- 拥有`决策顾问`。
- 拥有`AI责任倡议`。
- 公共影响力达到4。

即使个案失败，选择公开复核仍可推动后续政策，因此失败不等于无效选择。

### 中年期非法治疗

- 联结达到3，或拥有`地下互助`：获得`社区支援`，主角仍会被处罚，但不会完全失去社会关系。
- 其他情况：获得`制度惩罚`，老年时保障进一步降低，病房无现实访客。

## 政策环境判定

### 技术优先

优先条件：中年接受AI判定，或公共影响力不高且社会未出现重大反对事件。

表现：

- AI可以自动作出医疗和教育资源决定。
- 数字人格默认保留，退出需要申请。
- 延寿优先提供给高贡献、高资产和高数据完整度人群。

### 共生治理

优先条件：中年人类复核成功，或公共影响力达到4。

表现：

- 高风险决定必须有人类签名。
- 模型需提供证据和不确定性。
- 普通人可以获得有限延寿，但必须选择数据边界。

### 人本限制／社会冲突

优先条件：中年非法治疗，并拥有较高公共影响力或社区支援。

表现：

- 部分高风险AI被暂停使用。
- 线下社区和人工服务复兴，但资源分配效率下降。
- 若公共影响力不足，政策不转为人本限制，而是进入冲突状态：主角受罚，制度本身变化有限。

## 结局条件

| 最终选择 | 条件 | 主要结局 |
|---|---|---|
| 永生计划 | 保障≥4，且有`精英延寿资格`或政策已普惠延寿 | 永续节点 |
| 永生计划 | 不满足完整生物延寿条件 | 数据幽灵 |
| 有限延寿 | 公共影响力≥4，且有`复核胜诉`或`AI责任倡议` | 规则塑造者 |
| 有限延寿 | 其他情况 | 有边界的共生 |
| 删除数据 | 联结≥3，或有`小满羁绊`、`社区支援` | 人间余温 |
| 删除数据 | 其他情况 | 无痕离场 |

## 关键延迟回响表

| 早期选择 | 后期回响 |
|---|---|
| 全量芯片 | 教育和职业机会增加；老年数字化默认开启 |
| 监护型芯片 | 少年、中年和老年均可要求人工确认 |
| 拒绝植入 | 高端资源减少；数据删除最直接 |

| 签署小满报告 | 获得制度资源；老年可能只剩AI了解主角 |
| 公开申诉 | 个人可能受损，但公共影响力持续增加 |
| 秘密帮助小满 | 正规机会减少；获得地下互助和现实保护 |
| 最优人生合同 | 财富、健康和延寿机会增加；“栖”权限持续扩张 |
| 决策顾问 | 获得伦理经验和责任制度入口 |

## “栖”的人格变化规则

### 托管型

条件：自主≤1，且拥有`答案依赖`或`最优人生合同`。

措辞：

- “我已经替你完成。”
- “这是最优方案。”
- “无需担心，我会维护你的既定目标。”

### 共生型

条件：辨识≥3，且自主、保障没有极端失衡。

措辞：

- “你希望先看证据还是建议？”
- “这里存在我无法替你定义的价值。”
- “决定由你作出，我负责记录边界。”

### 工具型

条件：`无植入`，或自主≥4且多次限制AI权限。

措辞：

- “是否授权我介入？”
- “任务已完成，等待下一次调用。”
- “我无法访问你未提供的记忆。”

## 一致性要求

- 小满始终使用男性身份与“他”的指代；小满线是友情线，不得未经玩家设定改写为恋爱关系。
- 小满已经决裂时，不得在后续章节无条件作为亲密朋友出现。
- 周岚无论是否接受治疗，最终都会在老年章节前离世；区别是生命长度、告别方式和是否生成数字人格。
- 没有植入芯片不等于完全不用AI，只代表AI存在于可关闭的外部设备中。
- 全量芯片不等于必然进入坏结局，它可以提供真实的健康和教育收益。
- 删除数据不等于消灭所有公共记录，只删除可用于重建互动人格的个人数据；必要的匿名公共案例可以依照玩家授权保留。
- “栖”不能突然成为有恶意的反派。所有越界行为都来自既有授权、效率目标或制度默认值。
- 每条路线都必须同时呈现收益与代价，不使用红色“错误选择”提示。
