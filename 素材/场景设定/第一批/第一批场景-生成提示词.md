# 《余生协议》第一批场景生成记录

## 生成方式

- 模式：内置图像生成工具。
- 用途：Next.js 互动游戏横屏背景与动态 PPT 播片背景。
- 统一尺寸：1672×941 PNG。
- 画风基线：`素材/角色设定/角色总设定图-v2.png`。
- 场景一致性参考：已通过验收的前序场景作为后续场景参考。
- 所有最终图均为无固定人物、无最终 UI 的干净背景。
